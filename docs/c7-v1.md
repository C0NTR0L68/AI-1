# C7-v1 acceptance matrix

Scope approved by the owner on 2026-11-22. The trusted head is available
and intact. The archive namespace is on fixed local NTFS. Deployment has
separately enrolled every directory identity from the volume root to the
private archive directory. Owner and SYSTEM may administer that directory.

The archive implementation creates a new pending object with its protected
security descriptor and no handle inheritance. It holds the directory chain
until readback and rejects a final archive whose digest or ACL differs.
Already existing archives are never overwritten. SQLite continues to use a
private RAM image for note data. The test head uses a separate trusted,
test-only SQLite registry. This change does not provision or admit a deployed
head path. A deployment must provision the trusted registry, enroll its path
and ACL separately, and review the exact configuration before activation.

Simultaneous rollback of the local store and trusted head, or compromise of an
identity with authority to modify both, may return a stale state that still
authenticates. C7-v1 makes no freshness guarantee in that case. Abrupt physical
power loss is outside the observed synthetic evidence. See
[File Security and Access Rights](https://learn.microsoft.com/en-us/windows/win32/fileio/file-security-and-access-rights)
for Windows security descriptor semantics.

The matrix is ready for independent review. Source code and synthetic checks
do not authorize application wiring or change the disabled-by-default setting.
