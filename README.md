# AI-1 — MVP 0.1.0

Лёгкий локальный веб-интерфейс для общения с облачной моделью через OpenAI-compatible Chat Completions API.

## Возможности
- FastAPI backend и статический веб-интерфейс на русском.
- Сохранение истории диалога в SQLite.
- Настраиваемый API endpoint и модель.
- Понятное сообщение, если API-ключ не настроен или провайдер недоступен.
- Сервер по умолчанию запускается только на `127.0.0.1`.

## Запуск в Windows 11
Требуется Python 3.11 или новее.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

В `.env` локально укажи `AI1_API_KEY`. Не отправляй ключ в чат, Notion или GitHub. Открой http://127.0.0.1:8000.

## Тесты
```powershell
python -m pytest -q
```

Тесты используют подменный провайдер и не расходуют API-баланс. Реальный ответ модели требует действующего ключа и доступа к сети.

## Безопасность первой версии
- Не запускает команды ОС и не читает произвольные файлы.
- Не публикует сервер в локальную сеть; не меняй host на `0.0.0.0`.
- `.env` и локальная база исключены из Git.
